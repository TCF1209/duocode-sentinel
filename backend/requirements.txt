# --- document readers -------------------------------------------------
# 0.11.9 is the floor markitdown[pdf] imposes; pinning 0.11.4 under it made
# `pip install -r` fail outright with ResolutionImpossible — so a judge
# following the README could not install the project at all. 0.11.10 is the
# version every measured score in docs/SCORING.md was produced with.
pdfplumber==0.11.10       # PDF text + word coordinates (pure python)
